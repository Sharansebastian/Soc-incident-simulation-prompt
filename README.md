# Soc-incident-simulation-prompt

This repository contains a ChatGPT prompt designed to simulate realistic Security Operations Center (SOC) investigations for aspiring cybersecurity professionals. The prompt generates interactive incident-response scenarios based on common security events such as phishing compromises, malware infections, brute-force attacks, insider threats, data exfiltration, and web application attacks.

Each scenario presents a mix of SIEM alerts, authentication logs, endpoint telemetry, network activity, user reports, and system symptoms, including both malicious indicators and benign noise to mirror real-world SOC environments. Users are challenged to identify indicators of compromise (IOCs), determine the nature of the incident, recommend containment actions, and outline investigative next steps.

After each response, the prompt provides detailed feedback and scoring across key analyst competencies, including detection accuracy, IOC identification, containment strategy, and investigative reasoning. Scenarios can progressively increase in difficulty, making this prompt a valuable tool for SOC analyst interview preparation, blue-team training, log analysis practice, and incident-response skill development.
